# The cyber cast (design preview)

Jarvis (light), Ultron (shadow) and Juno (the one made of both), drawn in code. Open `cast.html` in a browser:
the buttons play every animation (idle, talk, listen, think, happy, wave, walk, dance, nap, blades, summon), show
the faces up close, and run Juno's startup.

Not part of the app yet: the next build moves these into the desktop characters (`ui/buddies.html`), adds the
wallpaper mode and plays Juno's startup at login.

- `rig.js` the shared skeleton, poses, hands
- `cyber.js` the three designs (chrome shells, light faces, swords, shards)
- `anims.js` the animations
- `startup.js` Juno's startup and the desktop world she becomes
- `scene.js` the preview page
